how it works

  • always-on visual cue: the orb breathes in and out at a steady 5.5s / 5.5s rhythm.
  • subtle on purpose: visible enough to guide breathing without hijacking attention.
  • returns you to breath: a gentle anchor that counters screen apnea over long sessions.

install (not notarized yet)

This alpha build is not notarized by Apple yet. macOS may block it on first launch.

  1. download the `.dmg` and drag Downshift into Applications.
  2. in Applications, right-click Downshift and choose Open.
  3. click Open in the Gatekeeper prompt.
  4. if blocked again: System Settings → Privacy & Security → “Open Anyway”, then retry.
